# VALTA-035 Global Arena
Single-file offline HTML, derived from VALTA-034. Portable vamos.arena.v1 entry contains run ID, player alias, action codes, optional human route and optional pasted AI route. Import replays mission choices and credit rules against the fixed mission definition; requires six missions complete, recalculates credit expenditure and attempts, validates graph paths. No submitted score fields trusted. Session-local duplicate run ID detection, maximum 100 entries, maximum 200 actions and 16 KiB input. Alias escaped on display. Human season ranking orders by credits used then attempts; route ranking orders human and pasted AI paths by cost with shared rank for ties. Entries can be copied or downloaded; import via JSON paste. English, Russian and simplified Chinese retained. No real server, persistent leaderboard, signatures, authenticated players or agent execution. A malicious user can construct a consistent winning transcript or change a run ID; replay is not anti-cheat or genuine Valta proof. Same C++-derived precomputed financial fixtures; no new C++ execution.
